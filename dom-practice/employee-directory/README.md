# Employee Directory

A responsive Employee Directory built with HTML, CSS, and vanilla JavaScript. Users can add employees, search by name, and view employee information in a clean, card-based interface.

## Features

- **Add Employees:** Add new employees by entering their name and department.
- **Form Validation:** Prevent empty submissions and display a helpful error message.
- **Live Search:** Filter employees by name as you type.
- **Dynamic Rendering:** Create and update employee cards using JavaScript DOM manipulation.
- **Responsive Design:** Adapt the layout for desktop and mobile screens.
- **User-Friendly Interface:** Clear the search filter after adding an employee so the updated directory is visible.

## Technologies Used

- HTML5
- CSS3 (Grid, responsive design, media queries)
- JavaScript (ES6+)

## JavaScript Concepts Practiced

- DOM selection and manipulation
- Event listeners (`submit` and `input`)
- Functions and parameters
- Arrays and objects
- `.forEach()`, `.filter()`, and `.includes()`
- Creating HTML elements dynamically
- Form validation
- Separating application data from DOM rendering

## How to Run

1. Download or clone the repository.
2. Navigate to `dom-practice/employee-directory/`.
3. Open `index.html` in a browser.
4. Add employees or use the search bar to filter the directory.

## What I Learned

This project helped reinforce how JavaScript arrays, functions, and DOM manipulation work together to create an interactive application.

I practiced separating the underlying employee data from the functions responsible for displaying it.

I also improved the user experience by building a responsive interface and resolving an issue where newly added employees were hidden by an active search filter.
